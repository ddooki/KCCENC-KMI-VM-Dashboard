# KCC건설 KMI 협력업체 관리 대시보드 (Vendor Management Dashboard)

KCC건설 KMI 협력업체 관리 및 평가 현황을 모니터링하기 위한 인터랙티브 웹 대시보드입니다.

## 📌 주요 기능
- **협력업체 종합 현황**: 등록 업체 수, 신규 등록, 안전/품질 우수 및 주의 업체 모니터링
- **공종별 / 등급별 분포 통계**: 건축, 토목, 설비, 전기 등 공종별 배분 및 A~D 등급 현황
- **협력업체 상세 평가 및 목록 조회**: 시공능력, 안전보건, 품질평가 점수 필터링 및 검색
- **리스크 관리 & 패널티 현황**: 부적격 및 관리 대상 협력업체 실시간 파악

## 🚀 실행 방법
- 저장소를 클론한 후 `index.html` 파일을 웹 브라우저로 실행합니다.
